Módulo 3

Onde colocar o código

Já tens o código gerado pela IA. Agora precisas de um lugar para colar isso e ver o teu site a ganhar vida — direto no telemóvel, sem computador. Vamos usar o Spck Editor.

Passo a passo

  1. Instala o Spck Editor na Play Store (é gratuito).
  2. Abre o aplicativo e toca em criar novo projeto.
  3. Dentro do projeto, cria um ficheiro chamado exatamente index.html — este nome é obrigatório.
  4. Apaga o conteúdo que vier por padrão e cola todo o código que a IA te deu, do <!DOCTYPE html> até ao fim.
  5. Guarda o ficheiro.
  6. Toca no botão de pré-visualização (geralmente um ícone de "play" ou "olho") para ver o site a funcionar dentro do próprio app.

Se o site vier mais de um ficheiro

Às vezes a IA separa o CSS num ficheiro à parte, chamado normalmente style.css. Se isso acontecer, cria também esse ficheiro dentro do mesmo projeto, com o mesmo nome que a IA indicou, e cola o conteúdo correspondente.

Se a pré-visualização não aparecer

O motivo mais comum é o nome do ficheiro principal estar diferente de index.html. Confirma o nome antes de tentar mais nada.
