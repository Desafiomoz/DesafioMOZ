Módulo 2 · continuação

Enviar as informações e receber o código

Agora que já sabes o que pedir, falta enviar isso à IA certa e entender o que vais receber de volta.

Quando a IA devolver o código

Vais receber um bloco de texto com tags como as que viste no Módulo 1. Copia tudo, do <!DOCTYPE html> até ao </html> final — é isso que vais colar no editor no próximo módulo.

Baixe o Claude e envie a informação completa do seu site.

Aqui está tudo sobre a lanchonete, para você perceber exatamente como fica um pedido completo enviado à IA:

Cria uma página HTML e CSS num único ficheiro para a minha lanchonete. Nome do site: Lanchonete Sabor da Esquina. Quero as seguintes seções: Contato e Sobre. Na seção Contato, coloca: número de telefone, e-mail e horário de atendimento. Na seção Sobre, coloca: uma descrição da lanchonete e a localização (Bairro Central, Maputo). Estilo: fundo preto e branco, com letras em tons que combinem bem. Capricha no visual. Coloca o HTML e o CSS num único ficheiro, com base neste estilo.

Depois de enviar, você receberá o código HTML completo do seu site — neste exemplo, o da lanchonete:

<!DOCTYPE html> <html lang="pt"> <head> <meta charset="UTF-8"> <title>Lanchonete Sabor da Esquina</title> <style> body { margin:0; font-family: Arial, sans-serif; background:#000; color:#fff; } header { padding:40px 20px; text-align:center; border-bottom:2px solid #fff; } header h1 { margin:0; font-size:2rem; } section { padding:30px 20px; max-width:600px; margin:0 auto; } section h2 { color:#f2a93b; } footer { display:flex; justify-content:center; gap:20px; padding:20px; border-top:2px solid #fff; } footer a { color:#fff; text-decoration:none; } </style> </head> <body> <header> <h1>Lanchonete Sabor da Esquina</h1> <p>O sabor que traz você de volta.</p> </header> <section id="sobre"> <h2>Sobre</h2> <p>A Lanchonete Sabor da Esquina fica no Bairro Central, em Maputo. Servimos lanches frescos feitos na hora, todos os dias.</p> </section> <section id="contato"> <h2>Contato</h2> <p>Telefone: 84 000 0000</p> <p>E-mail: contato@saborlanchonete.co.mz</p> <p>Horário: Segunda a Sábado, das 8h às 20h</p> </section> <footer> <a href="#sobre">Sobre</a> <a href="#contato">Contato</a> </footer> </body> </html>

Se algo parecer errado

Não tentes corrigir à mão ainda. Volta à IA e descreve o problema: "o botão não aparece", "as cores estão trocadas". Pedir de novo, com mais detalhe, é mais rápido do que tentar adivinhar.

Regra de ouro: um pedido, um objetivo. Em vez de pedir o site inteiro de uma vez, podes pedir secção por secção se for muito grande.
