Módulo 4

Publicar o site

O teu site já funciona no telemóvel. Falta um passo: colocá-lo online, com um link que qualquer pessoa no mundo pode abrir.

A forma mais simples: Netlify Drop

O Netlify tem uma opção onde arrastas os teus ficheiros e ele publica na hora, sem conta obrigatória para começar.

  1. No navegador do telemóvel, abre app.netlify.com/drop.
  2. No Spck Editor, exporta ou partilha os teus ficheiros (index.html e style.css, se existir) para a pasta de Downloads do telemóvel.
  3. Volta ao Netlify Drop e seleciona esses ficheiros para enviar.
  4. Em poucos segundos, o Netlify entrega um link como o-teu-site.netlify.app.

Guarda o teu link

Copia o link recebido e guarda-o num sítio seguro — nas notas do telemóvel, por exemplo. É esse link que vais partilhar no WhatsApp, Facebook ou Instagram para mostrares o teu site.

Quiseres um link mais profissional depois

Mais adiante, quando quiseres um endereço próprio (como oteunegocio.co.mz), podes comprar um domínio e ligá-lo ao mesmo site. Isso não é obrigatório para começar — o link gratuito já é um site real, no ar, visível para qualquer pessoa.

O site só fica visível depois deste passo. Antes de publicar, só tu vias o site no teu telemóvel — agora, qualquer pessoa com o link consegue abrir.
