Módulo 5 — Parte 2

Guia detalhado: do zero ao ZungaShop no ar

Aqui vais ver exactamente o que fazer em cada passo. Lê com atenção. Mais tarde, nos vídeos, vais ver tudo isto a acontecer no telemóvel.

1. A ideia

Antes de escrever qualquer código, precisas de ter uma ideia de site que faça sentido e que possa te dar dinheiro.

Não precisa de ser complicado. Pode ser:

• Uma loja de roupa
• Uma lanchonete
• Serviços de cabelo ou unhas
• Aluguer de casas
• Venda de telemóveis usados

No nosso exemplo vamos criar um site piqueno de venda no whatsapp o ZungaShop — uma loja online simples de roupa e acessórios.

Os produtos do ZungaShop

2. O pedido à Claude

Agora vais escrever o pedido (prompt) que vais enviar à IA. Tem de ser claro: o que queres, para quem, e como deve parecer.

Copia este pedido (ou adapta):

Cria um código HTML completo de uma página HTML e CSS de uma só página para uma loja online chamada ZungaShop. Preciso de: - Título com o nome da loja - Lista de produtos com foto, nome, marca e preço - Botão de WhatsApp em cada produto para comprar usa esse link: https://wa.link/llmw7t Produtos: 1. Camisa Social Premium — ClassicFit — 1.200 MZN 2. Calça Jeans Slim — UrbanWear — 1.800 MZN 3. Sapatos Casuais — StepMoz — 2.500 MZN 4. T-shirt Básica (pack 2) — ComfortDay — 900 MZN Cores: modernas e de confiança (escuro + dourado ou verde). O site deve funcionar bem no telemóvel.

3. Como copiar o código

A Claude vai devolver o código completo do site. Tens de copiar tudo:

1. Procura a primeira linha: <!DOCTYPE html>
2. Arrasta até à última linha: </html>
3. Copia tudo (pressiona longo → Copiar)

4. Colar no Spck Editor

Abre o Spck Editor no telemóvel e segue estes passos:

1. Abre o teu projeto (ou cria um novo chamado ZungaShop)
2. Abre o ficheiro index.html
3. Apaga tudo o que estiver lá dentro
4. Cola o código que copiaste da Claude
5. Guarda o ficheiro

5. Publicar (hospedagem)

Agora o site está no teu telemóvel. Para qualquer pessoa poder ver, precisas de o publicar (ex: Cloudflare Pages).

Os passos gerais são:

1. Exportar o projeto (ou os ficheiros)
2. Criar um projeto no Cloudflare Pages
3. Enviar os ficheiros
4. Esperar o site ficar no ar
5. Copiar o link final

Resumo rápido

1. Tens uma ideia (ZungaShop + produtos)
2. Escreves o pedido e envias à Claude
3. Copias o código completo
4. Colas no Spck Editor e guardas
5. Publicas e partilhas o link
