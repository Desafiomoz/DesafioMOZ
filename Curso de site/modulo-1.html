Módulo 1

Fundamentos

Antes de pedires código a uma IA, vale a pena entender o mínimo do que esse código significa. Não precisas decorar nada — só reconhecer as peças quando as vires.

O que é um site, na prática

Um site profissional é feito por códigos. O principal deles é o HTML — é ele que dá forma a tudo o que vês numa página.

Um site é feito de ficheiros de texto que o navegador (Chrome, por exemplo) sabe interpretar. O HTML descreve o conteúdo: títulos, textos, imagens, botões. O CSS descreve a aparência: cores, tamanhos, espaçamento.

A estrutura mínima

Todo o site começa com o mesmo esqueleto de código. Vais ver isto centenas de vezes — e é sempre assim que ele começa:

<!DOCTYPE html> <html> <head> <title>Título da aba do navegador</title> </head> <body> Tudo o que aparece na página vai aqui </body> </html>

As peças mais comuns

  • <h1> — o título principal da página
  • <p> — um parágrafo de texto
  • <img> — uma imagem
  • <a> — um link para outra página
  • <div> — uma caixa para organizar outras coisas dentro dela

Onde entra o CSS

O CSS diz como cada peça deve parecer. Por exemplo, dizer que um título deve ser dourado e grande:

h1 { color: gold; font-size: 32px; }

Não precisas de escrever isto de memória — no próximo módulo, é exatamente isto que vais pedir à IA para gerar por ti.

E o JavaScript?

Se o HTML é o esqueleto e o CSS é a roupa, o JavaScript é o que dá movimento. É ele que faz um botão reagir quando é tocado, uma mensagem aparecer sem recarregar a página, ou um menu abrir e fechar. É o que transforma um site parado num site vivo.

document.querySelector("button").onclick = function() { alert("Obrigado por visitares o site!"); };
Não precisas decorar nada disto. Só reconhecer o formato quando a IA gerar o código — para saberes se recebeste algo com sentido antes de colar no editor.
Os fundamentos são necessários. Não precisas de memorizá-los — o que precisas é de ter a noção de como eles são.
Não pules nenhum manual. Lê com calma, porque o teu futuro muda se entenderes o que está aqui.
